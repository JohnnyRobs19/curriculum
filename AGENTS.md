# AGENTS Instructions

Welcome to the CodeYourFuture curriculum repository! This file will help new contributors, even if you're new to open source.

## Before you start

- Read `README.md` and `CONTRIBUTING.md` for project context.
- You only need basic Git commands: `git add`, `git commit`, and `git push`.

## Making a change

1. Create or edit files.
2. Format your work with [Prettier](https://prettier.io/):

   ```bash
   npx prettier -w <files>
   ```

3. If the folder you edited has a `package.json`, run tests to check your changes:

   ```bash
   npm test
   ```

   Some areas have no tests; in that case this command will report there is no test script.

4. Use a clear commit message, for example:

   ```bash
   git commit -m "Brief description of change"
   ```

5. Push your branch and open a Pull Request.

## Need help?

- See `CONTRIBUTING.md` for detailed guidance.
- Ask in issues or community chat – everyone starts somewhere!
